# 收藏与评价

## 商品收藏

商品卡片和详情页提供收藏按钮，登录后可以收藏或取消收藏。收藏夹位于“我的账户 → 我的收藏”，每页展示 20 件商品。

收藏页支持选择数量并直接加入购物车；同款数量合并，库存、上下架和数量上限由购物车后端重新校验。

收藏记录保存在 `favorites` 表，按用户和商品唯一。重复收藏、重复取消不会生成额外记录，也不会影响其他用户。商品下架、软删除或分类停用后，已有收藏保留并显示“暂不可购买”，用户仍可取消收藏。

商品列表和详情页使用局部提交更新收藏状态，保留当前筛选和滚动位置。无 JavaScript 时使用普通表单提交。

## 购买后评分评价

订单流程为：模拟支付成功自动发货 → 顾客确认收货 → 完成后评价。已支付、仍为已确认的历史订单通过 `npm run db:init` 补为已发货；已发货订单在列表和详情提供“确认收货并评价”，确认后进入该订单的已完成评价列表。

入口位于“我的订单 → 已完成 / 评价”。已支付且已完成的订单，在列表内逐件展示商品名称、评分选项和评价输入框；也可以通过订单状态筛选选择“已完成”。

- 评分为 1–5 星，文字评价为 1–1000 个字符。
- 每条订单明细限评一次，购买数量不增加可评价次数；再次购买产生的新订单明细可以单独评价。
- 后端校验当前用户、订单归属、明细归属、支付状态与订单状态。未付款、待发货、已发货及已取消订单不能评价。
- 评价保存在 `reviews` 表，以订单明细唯一约束防止并发重复提交。已提交内容在原订单列表显示，不能通过重复请求覆盖。
- 商品详情显示平均评分、评价数量和分页列表，每页 10 条。统计只包含已支付、已完成订单的评价；评价作者名做部分遮盖，不展示邮箱或收货信息。
- 商品下架后，仍可评价已完成订单中的商品，订单商品名称使用下单快照。

## 数据库升级与验证

执行 `npm run db:init` 新建 `favorites` 和 `reviews` 表，不删除已有订单或商品数据。升级后重启网站。

`npm test` 覆盖收藏幂等与隔离、失效商品、评价资格、跨账号与跨订单明细访问、CSRF、输入校验、重复评价并发、文字转义及评分汇总。
