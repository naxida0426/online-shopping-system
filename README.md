# 拾光商城

在线购物网站课程设计。后端使用 Node.js、Express 和 MySQL，页面由 EJS 渲染，样式使用 Bootstrap 5 和自定义 CSS。页面以中文为主，支持电脑和手机浏览。

## 功能与进度

目前完成商品浏览和账户系统，尚未完成交易流程，也未部署到公网。

| 模块 | 已完成内容 |
| --- | --- |
| 首页与公共布局 | 品牌导航、分类、搜索、精选商品、公共页脚、响应式布局 |
| 商品浏览 | 关键词与分类组合筛选、每页 6 件分页、详情、库存显示、快速预览 |
| 顾客账户 | 注册、用户名或邮箱登录、退出、个人账户页、登录状态保持 |
| 数据与校验 | MySQL 持久化、参数化查询、密码加密、表单校验、登录访问限制 |

购物车、下单、模拟支付、订单历史、管理员商品与订单管理、销售统计、邮件确认将在后续完成。购物车入口目前用于验证登录限制，登录后仍显示待开发说明；商品购买按钮尚未启用。

初始化提供 4 个分类、6 件带“示例”标记的商品，用于课程演示。商品和账户均从 MySQL 读写，数据库故障时会显示错误提示，不使用前端假数据替代。

## 本机运行

需要 Node.js 20 或更高版本和 npm。数据库支持 MySQL 8.0.19+，推荐 8.4 LTS。

### Windows 首次安装

项目提供便携 MySQL 配置脚本，无需提前安装数据库。在项目目录打开终端执行：

```powershell
npm install
npm run mysql:setup
npm start
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。也可以用 `node app.js` 启动网站。

`mysql:setup` 首次下载官方 MySQL 8.4.13 ZIP（约 268 MB），初始化数据库和测试库，创建数据表与示例商品，并将随机数据库密码和会话密钥写入本机 `.env`。通常使用数据库端口 3307，冲突时自动选择空闲端口。重复执行会保留已有数据和密码。

**已有 Day 3 环境升级时**，先停止旧的网站进程，再执行以下命令即可，无需重新下载或清空数据库：

```powershell
npm install
npm run session:setup
npm run db:init
npm run db:check
npm start
```

以后重启电脑后执行 `npm run mysql:start` 和 `npm start`。停止网站用 Ctrl+C；停止数据库用 `npm run mysql:stop`。数据库文件保存在 `.local/mysql-data`，不要删除这个目录。

### 使用已有 MySQL

仅在 `.env` 不存在时复制 `.env.example` 为 `.env`，填写数据库连接信息，然后执行：

```powershell
npm install
npm run session:setup
npm run db:init
npm run db:check
node app.js
```

初始化账号需要建库、建表权限；运行账号只需项目数据库的读写权限。如果两个账号不同，在 `.env` 中填写 `DB_INIT_USER` 和 `DB_INIT_PASSWORD`。详细配置见 [数据库配置说明](docs/database.md)。

`.env`、`.local` 和 `node_modules` 不提交到 Git。仓库不提供默认网站账号，请通过注册页面创建顾客账号。数据库初始化账号与网站管理员是两回事。

## 页面与使用流程

| 地址 | 用途 |
| --- | --- |
| `/` | 商城首页 |
| `/products` | 商品列表，可组合使用 `q`、`category`、`page` 参数 |
| `/products/:id` | 商品详情，返回时保留原来的筛选条件和页码 |
| `/register` | 注册顾客账号 |
| `/login` | 用户名或邮箱登录 |
| `/account` | 我的账户，需要登录 |
| `/cart` | 需要登录，目前为购物车待开发页 |
| `/logout` | 仅接受带表单校验令牌的 POST 请求 |
| `/health/db` | 数据库连接及表结构检查，正常返回 200，异常返回 503 |

用户名支持 3–30 个中文、字母、数字或下划线，用户名和邮箱不能重复。密码至少 8 个字符，最多 72 个 UTF-8 字节；使用 bcrypt 加密后保存。登录后导航显示用户名和退出按钮，登录状态最长保留 8 小时。会话存储在 MySQL，重启 Node.js 不会直接丢失登录状态，退出或账号停用后不能继续使用旧会话。

账户表单使用 CSRF 校验，登录成功时更换会话编号。连续登录失败和注册请求设有频率限制，返回地址只允许本站页面。邮箱目前仅用于注册和登录，尚未验证邮箱所有权，也没有密码找回功能。

## 代码结构

```text
app.js                  应用入口、路由装配和错误处理
config/                 环境变量、MySQL 连接池、会话配置
routes/                 商品与账户路由
services/               商品查询、注册和密码验证
middleware/auth.js      当前用户加载、登录及管理员权限检查
utils/                  筛选分页、返回地址和表单校验工具
views/                  EJS 页面，公共组件放在 partials/
public/                 CSS、JavaScript 和 SVG 图片
sql/init.sql            数据表与示例商品
scripts/                数据库、会话密钥及便携 MySQL 配置命令
tests/                  配置、HTTP 和真实 MySQL 集成测试
```

数据库包含 `users`、`sessions`、`categories`、`products`、`cart_items`、`orders`、`order_items`、`payments` 共 8 张表。后四张交易表目前只有结构，不代表购物车、订单或支付已经实现。金额使用 MySQL DECIMAL，读取时保留为字符串，避免浮点精度问题。

`db:init` 可重复执行，不会覆盖已经修改的价格、库存或用户记录；已有表的字段变更需要单独迁移，不能靠重新初始化升级。

## 测试与课堂演示

```powershell
npm run db:check
npm test
```

配置了 `DB_TEST_NAME` 时，测试会连接独立的 MySQL 测试库，覆盖商品筛选分页、数据约束、注册与密码哈希、重复注册、登录失败、CSRF、退出、过期会话、账号停用和跨进程会话恢复。测试库名称必须以 `_test` 结尾，且不能与运行库相同。便携安装会自动准备测试库；未配置时相关测试会标记为跳过。

课堂演示可以按以下顺序进行：

1. 打开首页和商品列表，搜索“台灯”；选择“居家生活”后搜索“杯”，查看组合筛选结果。
2. 进入商品详情，检查价格、库存和 SKU，再返回原来的筛选结果。
3. 未登录访问 `/account` 或购物车，应跳转到登录页。
4. 注册一个演示账号，尝试重复注册、错误密码和正确登录，检查各自的提示。
5. 登录后打开“我的账户”，检查用户名、邮箱和顾客角色；刷新或重启网站，确认登录状态仍在。
6. 点击退出，再访问账户页，应重新要求登录。
7. 用浏览器手机模式检查导航、商品详情、注册和登录表单。

默认商品只有一页。自动测试会在测试库临时创建额外商品来验证分页，结束后清理，不向运行库添加测试商品。

修改后端代码后需要重新启动 `node app.js`。后续开发顺序为购物车、下单与模拟支付、订单历史、管理员功能、统计与邮件，最后进行公网部署和完整验收。部署时需配置 HTTPS、生产环境会话 Cookie、环境变量和数据库权限；本机便携数据库仅用于开发演示。
