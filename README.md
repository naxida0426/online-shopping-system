# 拾光商城 · 在线购物网站课程设计

基于 Node.js、Express 和 EJS 的中文在线商城，按阶段开发。本阶段完成响应式首页与公共布局。

## 本地运行

需要 Node.js 和 npm。在项目根目录执行：

```powershell
npm install
node app.js
```

也可以使用 `npm start`。打开 http://localhost:3000，按 `Ctrl+C` 停止服务。

默认端口为 3000；如端口已被占用，可在 PowerShell 中指定其他端口：

```powershell
$env:PORT = '3001'
node app.js
```

## 当前已完成

- Bootstrap 5 + 自定义 CSS，适配电脑、平板和手机。
- 品牌导航、搜索框、分类筛选、精选商品、商品预览弹窗与页脚。
- 搜索与分类通过 Express 查询演示数据；支持组合筛选、无结果提示和清除筛选。
- 登录 `/login`、注册 `/register`、购物车 `/cart` 提供明确的待开发说明。
- 公共 EJS header/footer，友好的 404 页面。
- Bootstrap、SVG 插画及图标均从本地提供，页面无需加载外部 CDN。

**当前商品、价格和插画仅为首页演示，不来自 MySQL，不代表真实库存，不支持购买。**
注册、登录、会话、真实商品详情、购物车、订单、模拟支付和管理员功能均未实现。
本阶段无需配置数据库，也没有数据库初始化脚本。仓库尚未提供自动化测试套件；默认 `npm test` 占位命令不可用。

## 目录说明

```text
app.js                       Express 入口、演示查询与占位路由
data/demo-products.js        明确标注的演示商品与分类
views/index.ejs              首页
views/message.ejs            待开发说明与 404 页面
views/partials/header.ejs    公共 head、导航与搜索
views/partials/footer.ejs    公共页脚与 Bootstrap 脚本
public/css/style.css         自定义样式与响应式规则
public/images/               本地 SVG 商品插画、图标及主视觉
```

后续 MySQL 接入点在 `app.js` 的首页路由：将演示数据过滤替换为参数化数据库查询，继续向模板传入 `products`、`categories`、`query`、`category`。商品展示字段见 `data/demo-products.js`。正式接入后再同步更新演示提示，不能在未验证持久化前声称数据库已完成。

## 人工验收

1. 启动后打开首页：导航、主视觉、5 个分类、6 件演示商品和页脚正常显示，演示说明清楚可见。
2. 搜索“台灯”：只显示对应演示商品，搜索词仍保留在输入框；按 Enter 和点击“搜索”都可提交。
3. 清除筛选后点击“居家生活”：显示 3 件商品，所选分类高亮；再搜索“杯”应只剩马克杯。
4. 搜索不存在的名称：显示无结果提示，点击“查看全部好物”可恢复列表。
5. 点击商品图片、名称或“查看预览”：弹窗展示对应内容，关闭按钮、Esc 和“继续逛逛”均可关闭。
6. 点击登录、注册、购物车：显示待开发说明，可以返回首页。
7. 访问 `/not-found`：返回 HTTP 404，并显示公共布局中的友好提示。
8. 缩小到手机宽度：导航折叠，点击菜单可展开搜索和账户入口；商品单列展示，页面不应横向溢出。
9. 使用 Tab 键检查焦点可见，弹窗关闭后焦点回到触发按钮。
10. 检查浏览器控制台和网络面板：本地 CSS、Bootstrap、SVG 正常加载，没有模板报错或缺失资源。
